# ml-study

Мой учебный трек по машинному обучению и анализу данных: соревнования Kaggle, ноутбуки, проекты.

## Окружение

Python 3.12, PyTorch с CUDA (RTX 4060).

```
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
```
